# T05 — World interaction: click-to-select villagers, selection ring, yield feedback

Fits: the loop works via the side panel, but the forest itself is inert. T05 makes the world
interactive and gives gentle feedback — the layer that makes it feel like a game, not a diorama.

Read `DESIGN.md` §2 (feel: gentle motion, 3 zones), §3 (updated RenderHandle / UIHandle contracts,
testability hook) first.

## Deliverable

1. **`src/render/villagers.ts`** — selection support:
   - Tag every villager mesh with `userData.villagerId` at rig creation.
   - `pick(raycaster: THREE.Raycaster): string | null` on the layer: return the `villagerId` of the
     closest hit, else `null`.
   - `setSelected(id: string | null)`: one shared soft selection ring (thin ring geometry, accent tone,
     low opacity) that appears under the selected villager and follows them every frame; gentle pulse
     (scale 1.0 → 1.08, ~1.2 s, eased). No ring when nothing is selected.
   - Expose `project(id: string, camera: THREE.Camera, out: THREE.Vector2): boolean` implemented by
     projecting the rig root position to NDC → client pixels helper in render/index.ts.
2. **`src/render/index.ts`** — implement the three new `RenderHandle` members:
   - `pickVillager(clientX, clientY)`: build NDC from the canvas rect, `Raycaster.setFromCamera`,
     delegate to the layer; `null` on miss.
   - `setSelected(id)`: delegate to the layer; keep the id so the ring survives frames.
   - `projectVillager(id)`: world → client px via camera; `null` if unknown.
3. **`src/ui/index.ts`** — add `select(villagerId: string | null)` to `UIHandle`:
   - External selection = same visual language as clicking a card: `.selected` on the card, popover
     open for that villager (name + 3 buttons + active state).
   - `null` clears selection and closes the popover.
   - Works before the first `render()` call (guard on `lastState`).
4. **`src/main.ts`** — wire world clicks:
   - `pointerdown` on the canvas records `(x, y)`; `pointerup` with total movement ≤ 6 px counts as a
     click (orbit drags must NOT select). On click: `ui.select(render.pickVillager(x, y))`.
   - Extend the testability hook: `globalThis.__cozy = { getState, projectVillager }`.
5. **`src/styles/ui.css`** — yield feedback: when `state.events` contains `chop`/`gather`, pulse the
   matching HUD pill (scale 1.0 → 1.06, ~200 ms, eased; retrigger-safe). Disable under
   `prefers-reduced-motion`. No layout shift, no new UI zone.

## Feel requirements

- The ring reads as "this one" at a glance: thin, warm accent, low opacity — never a hard outline.
- Feedback is a whisper, not a notification: no flashes, no color jumps, no numbers flying.

## Acceptance criteria

1. `pnpm exec tsc --noEmit`, `pnpm build`, `pnpm test` all exit 0; no new dependencies; no `any`.
2. Browser: click a villager's screen position (via `__cozy.projectVillager`) → that card gets
   `.selected`, the popover shows their name, the ring appears under them; click empty ground →
   selection clears; a 40 px drag on the canvas does NOT select.
3. Yields pulse the HUD pill (visible in a quick recording/screenshot pair), with no layout shift.
4. Console clean; `__cozyRender.info().calls` stays < 200.
5. Files ≤ ~220 lines; only the files listed above are touched.

## Constraints
