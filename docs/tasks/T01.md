# T01 — Scaffold + cozy UI shell + base scene

Fits: the first deliverable of a new game. It must already look and feel like the cozy game it
will become: the UI lands in this very first task (user requirement) and the scene establishes
the palette and camera language.

Read `DESIGN.md` first (binding). This brief adds the exact deliverables for this task.

## Deliverable

A Vite + TypeScript + Three.js project at the repo root that builds, tests and runs, with:

1. **Project setup** (hand-written, not `create-vite`): `package.json` (`"type":"module"`),
   `tsconfig.json` (strict, `noUncheckedIndexedAccess`), `vite.config.ts`, `index.html`, `README.md`.
   - deps: `three` only. devDeps: `typescript`, `vite`, `vitest`, `@types/node`.
   - scripts: `dev` = `vite` · `build` = `tsc --noEmit && vite build` · `preview` = `vite preview` ·
     `test` = `vitest run`.
   - `index.html`: `<title>Cozy Forest Village</title>`, Google Fonts Nunito (400;600;800) link,
     `<canvas id="world">`, `<div id="ui">`, `<script type="module" src="/src/main.ts">`.
2. **Sim stub** (`src/sim/types.ts`, `src/sim/index.ts`) — exact signatures from DESIGN §3, no
   behavior yet:
   - `createInitialState()` creates the 8 villagers (DESIGN roster, ordered hat colors), 40 tree
     nodes + 20 bush nodes + 1 campfire node (`campfire` at `{x:0,z:0}`), trees/bushes scattered
     in an annulus from r=6 to r=28 (deterministic, no `Math.random` — a small inline LCG is fine),
     `resources: { wood: 0, berries: 0 }`, `tick: 0`, `seed: 1`.
   - `assignTask()` sets `villager.task` only (no walk/behavior).
   - `tick()` is a no-op stub.
   - `src/sim/index.test.ts`: 2 small tests (initial state shape: 8 villagers, counters at 0;
     `assignTask` sets/clears task). This is also the vitest smoke test.
3. **Render scaffold** (`src/render/palette.ts`, `src/render/index.ts`) — contract from DESIGN §3:
   - WebGLRenderer on the given canvas: `antialias: true`, `setPixelRatio(Math.min(devicePixelRatio, 2))`,
     `shadowMap.enabled = true` + `PCFSoftShadowMap`, `setClearColor(PALETTE.sky)`.
   - Perspective camera (fov 45, near 0.1, far 200) at (16, 14, 16) looking at origin; `OrbitControls`
     (import from `three/addons/controls/OrbitControls.js`) with `enableDamping`, `dampingFactor 0.08`,
     `enablePan false`, distance clamp 10–45, `maxPolarAngle ≈ 1.35`.
   - `THREE.Fog(PALETTE.fog, 30, 95)`; `HemisphereLight(PALETTE.ambientSky, PALETTE.ambientGround, 0.8)`;
     `DirectionalLight(PALETTE.sun, 1.6)` at (18, 26, 10), `castShadow`, shadow camera ±30, mapSize 2048.
   - Ground: `CircleGeometry(60)` rotated flat, `MeshLambertMaterial({ color: PALETTE.grass })`, receives shadow.
   - Placeholder world from `state.nodes`: trees = shared trunk cylinder + cone foliage meshes (share
     geometry/material between all trees), bushes = squashed spheres, campfire = small stone ring + cone.
     These are temporary and clearly simple — T3 replaces them with instanced versions.
   - `RenderHandle.render(state, dt)` renders one frame; `resize()` updates camera/aspect/size;
     `dispose()` frees renderer/controls.
4. **Cozy UI** (`src/ui/index.ts`, `src/styles/tokens.css`, `src/styles/ui.css`) — contract from DESIGN §3,
   exactly three zones:
   - **HUD** (top-left): panel `id="hud"` with two pills; each pill = inline SVG icon + label + value.
     Selectors (stable, used by automated checks): `#hud [data-res="wood"]`, `#hud [data-res="berries"]`.
   - **Villager panel** (right side, ~250px): `id="villager-panel"` containing `#villager-list`;
     one `.villager-card[data-villager-id="<id>"]` per villager: hat-color dot, name, and
     `.task-label` showing `Idle` / `Chop wood` / `Gather berries` / `Rest`.
   - **Task popover**: opens when a card is clicked, anchored near the panel; three buttons
     `[data-task="chop"]`, `[data-task="berries"]`, `[data-task="rest"]` with labels `Chop wood`,
     `Gather berries`, `Rest`. Clicking a button calls `actions.assignTask(...)`, marks that button
     `.active`, and updates the card's `.task-label` on next `render()`. Escape or clicking outside
     closes it. Selected card gets `.selected`.
   - Styling: tokens.css exactly per DESIGN §4; Nunito; paper panels with 1px `--border` + `--shadow`;
     gaps on an 8px grid; `transition: 160ms ease` on interactive states; hover lifts shadow slightly.
     No pure black/white anywhere. `prefers-reduced-motion` disables transitions.
5. **Boot** (`src/main.ts`): create state → `initRender(canvas)` → `initUI(document.getElementById('ui')!, { assignTask })`
   where `assignTask` calls the sim then nothing else (UI re-renders next frame). Single rAF loop:
   `dt = min(now - last, 100)`; call `tick(state, dt)`, `render(state, dt)`, `ui.render(state)`;
   `resize` listener calls `render.resize()`. Expose `globalThis.__cozy = { getState: () => state }`.

## Acceptance criteria (all must hold)

1. `pnpm install`, `pnpm exec tsc --noEmit`, `pnpm build`, `pnpm test` all exit 0.
2. No `any`, no `@ts-ignore`, no `@ts-expect-error`, strict mode clean.
3. Dev server: zero console errors; canvas renders sky/ground/trees; window resize keeps aspect.
4. DOM behavior: 8 cards present; counter values `0`; clicking a card opens popover; clicking
   `[data-task="chop"]` adds `.active` to it and makes the card label show `Chop wood` after the
   next frame; Escape closes the popover.
5. Visual: palette per tokens; rounded corners; soft shadows; Nunito renders (fallback acceptable
   offline); no default-browser-looking controls.
6. Anti-bloat: no fourth UI zone, no settings, no modals, no extra panels.
7. Code hygiene: files ≤ ~220 lines each (split if larger); shared geometries/materials for
   repeated placeholder meshes; no external assets (no images/audio/fonts beyond Nunito link);
   comments only where intent isn't obvious.
