# T03 — Forest environment: instanced world, light, fog

Fits: T1 renders a placeholder forest. T03 replaces it with the real instanced environment that
makes the clearing feel bigger while staying cheap, and becomes the scene anchor that T4
(villagers) and T6 (ambient life) plug into.

Read `DESIGN.md` §2 (feel pillars), §3 (contracts, `__cozyRender` hook), §4 (palette values) first.

## Deliverable

**`src/render/environment.ts` (new)** — exports:

```ts
import type { ResourceNode } from '../sim';
export interface Environment { group: THREE.Group; update(timeSec: number): void; dispose(): void }
export function createEnvironment(nodes: readonly ResourceNode[]): Environment;
```

Content (all repeated objects are ONE `InstancedMesh` each — this is the point of the task):

- **Trees** — from nodes `kind === 'tree'` (40): one instanced trunk mesh + one instanced crown mesh.
  Per-instance position from the node; deterministic rotation/scale/hue variation derived from the
  node index (no `Math.random`); crown color via `setColorAt`, mixed between `foliageA`/`foliageB`.
  Crowns scale variation ≤ ±12%.
- **Bushes** — from nodes `kind === 'bush'` (20): one instanced mesh of squashed spheres.
- **Rocks** — one instanced mesh, 24 flat-shaded rocks scattered r=7…30 via an index-hashed rule
  (deterministic; not from nodes). No shadows.
- **Grass tufts** — one instanced mesh, 420 small cone tufts inside r=34 (deterministic hash),
  ≤ 0.5u tall, color variation between `tuftA`/`tuftB`. No shadows. Must read as soft texture, not clutter.
- **Wildflowers** — one instanced mesh, 60 tiny spheres inside r=4…30 mixing `flowerWhite`/`flowerPink`.
  No shadows, subtle.
- **Campfire area** — at the `campfire` node: keep T1's look (torus ring + cone flame via
  `MeshBasicMaterial` in `fire` color), plus a soft cream disc (radius 4.2, a warm paper/grass tone)
  so the village center reads as a clearing. This part may use regular meshes.

Shadows: tree trunks + crowns cast; ground receives. Rocks/tufts/flowers do not cast.

`update(timeSec)` is a **no-op hook** in T3 (T6 uses it for sway/ambient). Keep the signature.

**`src/render/index.ts`** — import `createEnvironment`, delete the placeholder world code
(`buildPlaceholderWorld`/`WorldKit`/`addTree`/`addBush`/`addCampfire` and related constants), keep
camera/lights/fog/controls/resize/RenderHandle exactly as they are. In `initRender`, expose
`globalThis.__cozyRender = { info: () => ({ calls, triangles, geometries, textures }) }` reading
`renderer.info` (declare the global).

**`src/render/palette.ts`** — add exactly these keys: `rock`, `tuftA`, `tuftB`, `flowerWhite`,
`flowerPink` using the DESIGN §4 values.

## Feel requirements

- Muted, warm, cohesive with the existing palette. Variation stays inside the two foliage/tuft tones.
- Tufts and flowers are seasoning: visible when you look, quiet at a glance. Nothing saturated.
- Fog and warm sun stay as-is.

## Acceptance criteria

1. `pnpm exec tsc --noEmit`, `pnpm build`, `pnpm test` all exit 0; no new dependencies.
2. Browser (dev server): console clean; screenshot shows a fuller, layered forest; every tree/bush
   node is represented; sun shadows visible on instanced trees; campfire reads clearly.
3. `__cozyRender.info()` reports `calls < 80`, `triangles < 400000`, `geometries < 30`.
4. Placeholder code fully removed from `src/render/index.ts`; files ≤ ~220 lines; no `any`.
5. Variation is deterministic (same seed → same look) and derived only from indices/ids.

## Constraints

- Touch only: `src/render/environment.ts` (new), `src/render/index.ts`, `src/render/palette.ts`.
- Materials: `MeshLambertMaterial` for the world, `MeshBasicMaterial` only for the flame. No textures.
- No new dependencies. No `any`. Do not alter the public `RenderHandle` contract.
- **Do not commit.** Orchestrator validates and commits.
- Do not dispatch subagents.
