1. **Structure ring** — add the six build spots per DESIGN §3.2 (angles 30°–330°, r=5.2, kinds:
   pot, bench, garden, lantern, lantern, feeder; ids `pot`, `bench`, `garden`, `lantern-a`,

2. **`buildStructure(state, id)`** — per DESIGN §3.2: spend the cost (pot 20 wood · bench 15 ·
   garden 25 · lantern 10 · feeder 10 wood + 5 berries), set built, emit `built`;

   `fedMs = 60000`, emit `eat`. `fedMs` decays by `dtMs` every tick; while `> 0` the work period is
   **1190 ms** (15 % faster) for chop/berries.
5. **Garden** — while built: `gardenMs += dt`; each 30000 ms → berries +1.

2. Cook: with pot built and 10 berries/5 wood → first meal after the 3000 ms channel; resources fall by
   3/1 per meal; loop continues; when berries < 3 → idle, task null.
3. Cook with no pot → not actionable (idle).
4. Eat: meals 1, fuel 70, rest assignment → on rest: meals 0, `fedMs = 60000`, rest lasts 5500 ms,
   `eat` emitted. With fuel 10 (dim) → no consumption.
5. Fed: while `fedMs > 0` a chop yield lands at the 1190 ms boundary; `fedMs` decays to 0 and the
   period returns to 1400 ms.
6. Garden: built → +1 berry per 30000 ms; unbuilt → nothing.
