# T06 — Ambient life + procedural WebAudio

Fits: the village is alive but silent and still between tasks. T06 adds the sparing ambient layer
that carries the cozy feeling — and the audio, synthesised entirely in code (no asset files), which
also sidesteps the usual "AI can't make audio" limitation.

Read `DESIGN.md` §2 (feel pillars — ambient life is *sparing*, motion is *gentle*) and §4 (palette).

## Deliverable

### 1. `src/render/ambient.ts` (new)

```ts
import type { GameState } from '../sim';
export interface AmbientLayer { group: THREE.Group; update(state: GameState, timeSec: number, dtMs: number): void; dispose(): void }
export function createAmbient(): AmbientLayer;
```

- **Birds** — 6, on wide slow circles above the clearing: radius 9–16, height 7–12, angular speed
  0.05–0.09 rad/s, gentle vertical bob; wing flap ±0.35 rad at ~3 Hz with per-bird phase. Bird tone
  `PALETTE.bird`; simple silhouettes (body + two wing flaps). They never descend. Use instanced
  meshes (body + wings ≤ 3 draw calls) — not 18 individual meshes.
- **Butterflies** — 8, wandering r=2…14 of centre at y 0.4–1.4 along slow sin/lissajous paths
  (≤ 0.4 u/s), wing flap ~7 Hz with tiny amplitude; wings mix `PALETTE.flowerWhite` / `PALETTE.flowerPink`.
- **Motes** — one `THREE.Points`, 60 soft drifting specks inside r=20, slow sinusoid drift, color
  `PALETTE.mote`, opacity ~0.5, small size. One draw call. Must read as air, not snow.
- Everything deterministic (hash-derived phases, no `Math.random`); nothing aggro, nothing loud.

### 2. `src/render/environment.ts` — breeze

Extend the existing `update(timeSec)` no-op hook: tree crowns sway gently (per-tree phase, tilt
amplitude ≤ 0.03 rad around each crown's base, slow ~0.6–1.0 Hz). Trunks stay put. Per-frame cost
must stay trivial (40 crowns). Keep the existing exports and behaviour otherwise identical.

### 3. `src/render/index.ts`

Create the ambient layer once (like environment/villagers), add to the scene, call
`update(state, performance.now() / 1000, dtMs)`, dispose it.

### 4. `src/render/palette.ts`

Add exactly: `bird`, `mote`. Also add `accent` equal to the CSS `--accent` value (`#e08a3c`) and use
it for the selection ring in `src/render/villagers.ts` (replaces the `PALETTE.fire` mirror — `fire`
stays for the flame).

### 5. `src/audio/index.ts` (new) — procedural WebAudio, zero assets

```ts
import type { GameState } from '../sim';
export interface AudioHandle { update(state: GameState, dtMs: number): void; dispose(): void }
export function initAudio(): AudioHandle;
```

- **Lazy start**: create/resume the `AudioContext` on the first real `pointerdown`/`keydown`
  (once, window-level). Before that, `update` is a no-op. Init failure is swallowed silently.
- **Bed**: looped filtered noise (wind) — lowpass ~400 Hz, slow LFO on gain; plus a very quiet warm
  pad (two detuned sines, gain ≤ 0.02). Master gain ~0.12; everything gentle.
- **Chirps**: every 4–12 s, a short cluster of 3–5 sine blips (1.5–3.8 kHz, 60–120 ms, fast decay,
  random pan). Use a tiny seeded PRNG local to the module — no `Math.random`.
- **Event SFX** from `state.events`: `chop` → short muffled wood knock; `gather` → soft upward
  pluck; `rest-done` → quiet two-note chime. No event spam: sounds only on the events present.
- **Hook**: `globalThis.__cozyAudio = { state: () => ctx?.state ?? 'none', started: () => started }`.
- No UI of any kind (no volume slider — anti-bloat rule).

### 6. `src/main.ts`

`const audio = initAudio();` after the UI setup; call `audio.update(state, dt)` in the frame loop
(before or after `ui.render` — your choice). Nothing else changes.

## Acceptance criteria

1. `pnpm exec tsc --noEmit`, `pnpm build`, `pnpm test` all exit 0; no new dependencies; no `any`.
2. Browser: console clean on a fresh load; birds/butterflies/motes visibly move (positions change
   between two samples ~2 s apart); crowns sway; no visual clutter — ambient stays a whisper.
3. `__cozyRender.info().calls < 200` after the additions; `triangles < 600000`.
4. `__cozyAudio` exists; `state()` is `'none'` before any gesture and no errors occur without one.
   (Synthetic events do not count as browser user activation — audible output is a human playtest
   check; do not force-start audio to "prove" it.)
5. Files ≤ ~220 lines each; only the files listed are touched.

## Constraints

- Touch only: `src/render/ambient.ts` (new), `src/render/environment.ts`, `src/render/index.ts`,
  `src/render/palette.ts`, `src/render/villagers.ts` (accent swap only), `src/audio/index.ts` (new),
  `src/main.ts`.
- No textures, no external assets, no dependencies. Materials `MeshLambertMaterial`/`MeshBasicMaterial`,
  Points with `PointsMaterial` (vertex colors fine).
- **Do not commit.** Orchestrator validates and commits.
- Do not dispatch subagents. Keep to the 3 UI zones (none added).
