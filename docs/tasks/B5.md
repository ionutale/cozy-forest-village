# B5 — Render: structures (built + ghosts) and world picking

Fits: batch 2's village growth needs bodies in the world. Read `DESIGN.md` §2, §3 (`Structure`,
`RenderHandle.pickStructure`) and §3.2 (catalog + spots).

## Deliverable

1. **`src/render/structures.ts`** (new):
   ```ts
   export interface StructuresLayer { group: THREE.Group; update(state: GameState, timeSec: number): void; dispose(): void }
   export function createStructures(): StructuresLayer;
   ```
   - One model per built structure (id via `userData.structureId` on every mesh):
     - `woodpile`: stacked log cylinders + a stump base (always built).
     - `pot`: stone ring + cauldron sphere + wooden stirrer; a small stack of bowls for
       `min(pot.meals, 6)`; faint steam wisp when `meals > 0`.
     - `bench`: two log legs + a plank seat.
     - `garden`: tilled patch (dark disc) + 5-6 sprouts whose scale grows with
       `min(1, gardenMs / 30000)`, staggered.
     - `lantern` (×2): post + warm lamp head + a small `PointLight` (distance ≈ 6, intensity ≈ 0.5,
       no shadows — 3 point lights total with the fire is the budget).
     - `feeder`: post + tray + tiny seeds.
   - Unbuilt structures render as **ghosts**: same geometry, single translucent material
     (`opacity ≈ 0.22`, no shadows), gentle nothing (static is fine).
   - Meshes reuse shared geometries/materials where possible; built meshes cast shadows, ghosts don't.
2. **`src/render/index.ts`** — create/update/dispose the layer; add
   `pickStructure(clientX, clientY): string | null` to `RenderHandle` (raycast, closest hit,
   works for ghosts and built alike). Selection state stays independent from villagers'.
3. Palette additions only if needed (muted).
