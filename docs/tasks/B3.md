# B3 — Persist: localStorage save / load / autosave (final schema v1)

Fits: after B2 the `GameState` shape is final for batch 2 — persist it now so later tasks are built on
top of a game that survives reloads. Read `DESIGN.md` §3 first.

## Deliverable

1. **`src/persist/index.ts`** (new):
   - `STORAGE_KEY = 'cozy-forest-village.save'`, `VERSION = 1`.
   - `loadGame(storage: Storage = localStorage): GameState | null` — parse `{version, state}`; accept
     only `version === 1` and a plausible shape (`villagers`, `nodes`, `structures` arrays; `fire`,
     `pot` objects); any failure (missing, bad JSON, wrong version, wrong shape) → `null`. Never throws.
   - `saveGame(state: GameState, storage: Storage = localStorage): void` — write `{version, state}`;
     swallow quota/serialization errors.
   - `clearSave(storage: Storage = localStorage): void`.
   - `startAutosave(getState: () => GameState, storage: Storage = localStorage): () => void` — every
     **3000 ms**, save only when `state.tick` changed since the last save; returns a stop function.
   - JSON only: the `GameState` is plain data (no Maps/class instances) — that is guaranteed by DESIGN §3.
2. **`src/persist/index.test.ts`** (new) — in-memory `Storage` fake: round-trip deep-equal; wrong
   version → null; corrupt JSON → null; missing arrays → null; `clearSave` empties; autosave writes once
   per tick change and not twice without change (use vitest fake timers).
3. **`src/main.ts` wiring** — `const state = loadGame() ?? createInitialState();` and start autosave;
   on `pagehide`, `saveGame(state)` **before** disposing the layers; keep everything else intact.

## Acceptance

`pnpm exec tsc --noEmit`, `pnpm build`, `pnpm test` green (persist suite included); no `any`.
Orchestrator will verify in the browser: build something → wait 4 s → reload → it persists; corrupted
storage → clean fresh boot.

## Constraints

- Touch only `src/persist/**`, `src/main.ts`, `docs/tasks/B3-report.md`. No new deps. Do not commit.
  No subagents. Do not change sim/render/ui/audio.
