# T04 — Villagers: primitive characters with hats + procedural animation

Fits: T1–T3 built the shell, sim, and environment. T04 adds the villagers themselves — the piece
that carries the cozy feel. Per DESIGN §2 pillar 2, character reads as cozy via **hats and
proportions** (big head, small body), not detail.

Read `DESIGN.md` §2 (feel pillars), §3 (contracts, `Villager.facing` / `progressMs`), §4 (palette) first.
Also read `src/sim/types.ts` — the `Villager` fields you consume.

## Deliverable

**`src/render/villagers.ts` (new)** — exports:

```ts
import type { GameState } from '../sim';
export interface VillagersLayer {
  group: THREE.Group;
  update(state: GameState, timeSec: number, dtMs: number): void;
  dispose(): void;
}
export function createVillagers(): VillagersLayer;
```

**Character build** (one `THREE.Group` per villager, shared geometries/materials across all 8):

- Body: small rounded form (~0.5u tall, radius ~0.16) in a shared warm neutral tone; total villager
  height ~0.95u.
- Head: sphere, radius ~0.15 (big-head proportion), shared skin tone (pick a muted warm value and
  add it to `palette.ts` as `skin`; also add `tunic` for the body tone).
- Hat: cone (~0.2u tall, radius ~0.17) in the villager's `hatColor`, plus a small pom sphere on top
  (same color, slightly darker). Hats are the identity cue — make them read cleanly at distance.
- Arms: two small capsules (~0.18u), shared geometry; they swing during walking.
- Villager meshes cast shadows.

**Animation** (all procedural, driven only by `timeSec`/`dtMs` + state — no extra rAF, no CSS):

- Idle: micro bob (`sin` ±0.015u) at a slow rate; arms still.
- Walking: move group to `state.pos` (x,z), face `state.facing` with shortest-arc smoothing
  (e.g. `cur += angleDelta(cur, target) * (1 - exp(-dtMs * 0.012))`) so turning never snaps;
  add a step bob and opposite arm swings.
- Working: rhythmic motion per task — `chop`: forward lean pulses (~2.2 Hz); `berries`: gentler
  lean (~1.3 Hz); both keep facing the target node.
- Resting: relaxed slow breathing bob (no lean).
- Gentle everywhere: no snappy transitions (pillar 4).
- Visual state (current facing, phase offsets per villager to avoid synchronised robots) lives in
  the layer, not in the sim.

**`src/render/index.ts`** — create the villagers layer once (like the environment), add its group to
the scene, call `layer.update(state, performance.now() / 1000, dtMs)` from `render()` (use the real
`dtMs` param now, not `_dtMs`), dispose it in `dispose()`.

**`src/render/palette.ts`** — add exactly: `skin`, `tunic` (muted warm values of your choice).

## Acceptance criteria

1. `pnpm exec tsc --noEmit`, `pnpm build`, `pnpm test` all exit 0; no new dependencies.
2. Browser: console clean; 8 villagers visible around the clearing with 8 distinct hat colors;
   screenshot evidence.
3. Behavior (browser, via `__cozy.getState()` + screenshots): assigning `chop` to a villager makes
   them walk toward a tree (position moves, distance decreases); after arrival they play the work
   motion; `rest` leads to the campfire; no teleporting, no visible snapping.
4. `__cozyRender.info()`: `calls < 120`, `triangles < 500000` (total scene, not just villagers).
5. Files ≤ ~220 lines; no `any`; only the files named above touched.
