# B4 — Render: fire visuals + warm light tied to fuel

Fits: the fire is a static cone today; batch 2 makes it the village's heartbeat. Read `DESIGN.md`
§2 (feel), §3.2 (fire states) and reuse `PALETTE`.

## Deliverable (`src/render/environment.ts`, `src/render/palette.ts`)

1. **Flame by fuel** — scale = `0.25 + 0.75 · fuel/max`; at `fuel = 0` the flame cone shrinks to a
   faint ember tint (or hide the cone and show small ember dots — your call, keep it cozy).
2. **Warm point light** — one `THREE.PointLight` at the fire (y ≈ 1.1, distance ≈ 14, decay 2):
   intensity `0.25 + 1.15 · fuel/max`, color `PALETTE.fire`; subtle flicker (±6 %, slow two-sine noise,
   deterministic). No shadows from this light (perf).
3. **Flicker on the flame** — gentle scale/position wobble (±6 %), always eased, never strobing.
4. **Embers** — when fuel = 0: a small dim glow (dark orange) instead of a tall flame; the clearing
   visibly cools.
5. `PALETTE` may gain one `ember` key if you need it (muted dark orange, e.g. `#a5502f`).
