# Bonds Implementation Plan (batch 9)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development
> (recommended). **Repo adaptation (binding):** each task below is one file-disjoint dispatch;
> implementers NEVER run git, the browser, or `pnpm dev` — the orchestrator runs the freeze gate,
> the live pass, and commits per task. Steps use `- [ ]` checkbox syntax for tracking.

**Goal:** Villager friendships grow from pure proximity — 4 levels, never decaying — with a gentle
work synergy between close friends, heart puffs on level-ups and reunions, a card heart mark and a
Bonds line in the popover, all deterministic and saved (schema v6).

**Architecture:** A new `src/sim/bonds.ts` owns a 12×12 pair table (`scores` + `gapMs`), advanced
per tick from distances alone; level crossings and reunions push sim events; the work-yield path
reads one helper for the ×0.9 synergy; UI and render consume derived helpers and the existing
hearts path; persist v6 stores scores only.

**Tech Stack:** TypeScript, three.js (no new dependencies), vite, vitest.

**Spec:** `docs/superpowers/specs/2026-10-06-bonds-design.md`

## Global Constraints

- No new dependencies. No `any`. No new UI zones (§6 allowance covers the card mark + Bonds line
  only). Deterministic sim: no `Math.random`, no `Date`, no wall-clocks — only `tick`'s `dtMs`.
- Schema target **v6** (after batch 8's v5); chain **v1 → … → v6** with post-migration
  `isPlausibleState` re-validation on every branch. `gapMs` is never saved.
- Baseline: **282/282, 15 files** before this wave; it must stay green plus your additions.
- Concurrent tree: touch only your task's files. Out-of-scope concurrent reds: note + re-run
  (don't fix). Free models may rate-limit: retry the gate a few times before reporting.
- Implementers never commit; the orchestrator gates, live-verifies and commits per task.

## Review Focus

1. **No heart spam**: `bond-up`/`bond-reunion` fire only on real transitions — never per tick while
   a pair stays close — pinned in **K1** tests and re-checked live.
2. **The perk is exact and leak-free**: `×0.9` only for a working villager within 3.0 u of a
   level-≥2 partner; every other timer byte-identical — **K1** tests.
3. **Giant-`dt` and extreme-score safety**: one enormous tick cannot corrupt levels or push scores
   past `BOND_SCORE_MAX` into invalid saves — **K1** test + **K2** validation cap.
4. **v1 → v6 intact**: ancient saves load with zeroed bonds, the village intact, scores round-trip
   exactly — **K2** tests.
5. **The fiction holds**: fast-forwarded evenings produce close bonds specifically with the
   seat-neighbors around the fire — **K1** test + live screenshots.
